Selamat datang di **BAB 12 — Mini Project Collection**! 🚀

Ini adalah titik balik penting dalam perjalanan belajarmu. Dari BAB 1 hingga BAB 11, kamu telah mempelajari seluruh teori, konsep, dan aturan HTML:
- Fondasi, Teks, Link, Media, Tabel, & Form (BAB 1–6)
- Atribut, Semantik, Metadata, & Aksesibilitas (BAB 7–10)
- Best Practices & Clean Code (BAB 11)

Sekarang, pertanyaan utamanya adalah: **"Dapatkah kamu mengubah kebutuhan website nyata menjadi struktur kode HTML yang tepat tanpa bergantung pada tutorial langkah demi langkah?"**

---

## 🎯 Pergeseran Pola Belajar (Learning Pattern Shift)

Mulai BAB 12, pola pembelajaran berubah total:

```
❌ POLA LAMA (BAB 1-11):
Teori → Contoh Kode → Penjelasan → Latihan Kecil

✅ POLA BARU (BAB 12):
BRIEF → ANALYSIS → REQUIREMENTS → THINK → BUILD → AUDIT → REFLECT
```

Kamu tidak akan lagi diberikan kode lengkap untuk di-copy-paste. Sebaliknya, kamu diberikan **Project Brief nyata** (skenario, masalah, kebutuhan pengguna, dan batasan) lalu kamu sendiri yang merencanakan dan membangun HTML-nya dari nol.

---

## 📐 Metode 7-Langkah Pengerjaan Mini Project

Untuk setiap proyek di BAB 12, ikuti alur kerja profesional ini:

1. **Read Brief**: Baca skenario dan kebutuhan calon pengguna.
2. **Analyze Requirements**: Tentukan data apa yang harus ditampilkan dan diinputkan.
3. **Plan Structure**: Rencanakan struktur hirarki dokumen (`header`, `nav`, `main`, `section`, `article`, `footer`).
4. **Build HTML**: Tulis kode HTML yang valid, semantic, dan clean.
5. **Check Accessibility**: Pastikan alt text, label form, dan navigasi keyboard berfungsi.
6. **Audit & Validate**: Uji kode di W3C Validator (`validator.w3.org`) hingga 0 Error.
7. **Reflect**: Evaluasi keputusan teknis yang telah kamu buat.
