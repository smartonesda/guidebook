Ketika sebuah proyek website berkembang dari 5 halaman menjadi 500 halaman dengan puluhan developer yang berkontribusi, menulis CSS tanpa arsitektur akan berujung pada kekacauan (spaghetti CSS).

Di BAB 10 ini, kamu akan mempelajari:
- CSS Custom Properties (`--variable-name`) & scoping dinamis
- Design Tokens: Single Source of Truth untuk warna, font, spacing, dan radius
- Dark mode instan berbasis tokens
- Metodologi penamaan terstruktur BEM (Block, Element, Modifier)
