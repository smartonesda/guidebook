Kembali lagi di HTML Guidebook! Di BAB 5 kemarin, kita sudah berhasil merapikan data portfolio kita menggunakan tag daftar (*lists*) dan menyajikan perbandingan data teknis proyek dalam bentuk tabel data (*tables*).

Namun, ada satu bagian penting yang masih pasif: bagian **Kontak**. Saat ini, pengunjung hanya bisa mengklik tautan email untuk mengirim pesan. Bagaimana jika mereka ingin mengirim pesan atau mengajukan kerja sama langsung di website-mu?

Di sinilah kita membutuhkan **HTML Forms**.

Di **BAB 6 — Forms** ini, kita akan belajar **bagaimana halaman web menerima masukan (input) dari pengguna**. 
- Jika bab-bab sebelumnya fokus pada *menampilkan data*, maka BAB 6 ini adalah pintu gerbang pertama kita untuk *menerima data*.
- Kita akan membangun sebuah **Contact & Project Inquiry Form** interaktif di website portfolio kita agar pengunjung bisa langsung mengirimkan pesan kepada kita.

---

## 🎯 Target Pembelajaran BAB 6

Setelah menyelesaikan bab ini, kamu akan mampu:
- Menjelaskan konsep kerja formulir HTML dalam mengumpulkan dan mengirim data.
- Menuliskan tag utama pembungkus formulir (`<form>`) beserta atribut `action` dan `method`.
- Menggunakan tag `<label>` secara aksesibel menggunakan atribut `for` yang terhubung dengan `id` input.
- Menyusun elemen input teks (`<input type="text">`), email, sandi, angka, pilihan bulat (radio), pilihan ganda (checkbox), hingga berkas (file).
- Merancang isian teks panjang menggunakan `<textarea>` dan pilihan menu pilihan menggunakan `<select>`.
- Mengelompokkan formulir secara rapi menggunakan tag `<fieldset>` dan `<legend>`.
- Menerapkan sistem validasi bawaan browser (*HTML5 form validation*) seperti atribut `required`, `minlength`, dan `pattern`.

## 🗺️ Peta Pelajaran BAB 6

Berikut adalah urutan materi yang akan kita pelajari bersama:

- **6.2 Elemen Form**: Memahami tag `<form>`, fungsi atribut `action`, `method`, dan konsep kirim data (GET vs POST).
- **6.3 Label & Input**: Menghubungkan label dengan input secara aksesibel menggunakan atribut `for` dan `id`.
- **6.4 Tipe-Tipe Input**: Membedakan input teks, email, radio button, checkbox, dan tombol submit.
- **6.5 Pilihan Dropdown & Textarea**: Menyusun pilihan dropdown `<select>` dan isian teks panjang `<textarea>`.
- **6.6 Validasi Form Bawaan**: Menerapkan atribut pembatas input untuk mencegah data kosong atau salah format.
- **6.7 Studi Kasus**: Membangun Contact & Project Inquiry Form di dalam halaman utama portfolio.
- **6.8 Mini Project**: Melengkapi formulir kontak di website portfolio pribadimu.
- **6.9 Challenge**: Tantangan mandiri membuat formulir pendaftaran siswa baru.
- **6.10 Error Corner**: Mengulas kesalahan fatal pemula dalam penamaan atribut radio button dan label.
- **6.11 Ringkasan**: Rangkuman seluruh atribut dan elemen formulir beserta kegunaannya.
