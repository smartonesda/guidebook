title: "6.0 Introduction — Modern Flexbox (1D Layout)"
description: "Menguasai Flexible Box Layout Module — sumbu utama (Main Axis), sumbu silang (Cross Axis), perataan ruang, dan distribusi fleksibel."
---

Flexbox (Flexible Box Layout) adalah sistem tata letak satu dimensi (1D) paling serbaguna dalam CSS.

Flexbox dirancang untuk mendistribusikan ruang dan meratakan elemen di dalam container, bahkan ketika ukuran elemen tidak diketahui atau bersifat dinamis.

Di BAB 6 ini, kamu akan menguasai:
- Sumbu Utama (Main Axis) vs Sumbu Silang (Cross Axis)
- Perataan: `justify-content`, `align-items`, `align-content`
- Fleksibilitas Item: `flex-grow`, `flex-shrink`, `flex-basis`
- Jarak antar item modern: `gap`
