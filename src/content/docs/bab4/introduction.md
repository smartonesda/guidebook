Kembali lagi di HTML Guidebook! Di BAB 3 kemarin, kita sudah berhasil menghubungkan halaman web kita menjadi struktur multi-halaman (*multi-page*) yang terhubung melalui menu navigasi dan tautan aktif.

Namun, halaman portfolio kita masih terasa sangat sepi karena hanya dipenuhi oleh deretan teks.

Sekarang, kita masuk ke **BAB 4 — Gambar & Multimedia**.

Di bab ini, kita akan belajar bagaimana **memasukkan dan mengelola konten multimedia** ke dalam halaman web kita. Ingat analogi ini:
- Di **BAB 1**, kita telah **membangun rumahnya** (struktur dasar).
- Di **BAB 2**, kita telah **mengisi dan menyusun isi rumahnya** (konten teks).
- Di **BAB 3**, kita telah **membuat pintu dan lorong jalan** (tautan navigasi).
- Di **BAB 4** ini, kita akan **memasang jendela kaca bermotif, memutar musik latar, dan memasang layar televisi** di dalam rumah kita (aset gambar, suara, video, dan frame eksternal)!

---

## 🎯 Target Pembelajaran BAB 4

Setelah menyelesaikan bab ini, kamu akan mampu:
- Menjelaskan bagaimana browser memproses permintaan file media dari server secara terpisah.
- Menuliskan elemen gambar (`<img>`) dengan atribut `src` dan `alt` secara valid.
- Mengatur ukuran dimensi gambar untuk mencegah pergeseran tata letak (*layout shift*).
- Menyusun pengelompokan gambar dan teks keterangan menggunakan `<figure>` dan `<figcaption>`.
- Menerapkan konsep dasar gambar responsif menggunakan tag `<picture>`.
- Memasang pemutar audio (`<audio>`) dan video (`<video>`) bawaan browser lengkap dengan kontrolnya.
- Menyematkan peta atau video luar menggunakan elemen bingkai (`<iframe>`).
- Mengorganisasikan file media ke dalam folder aset secara rapi.

---

## 🗺️ Peta Pelajaran BAB 4

Berikut adalah urutan materi yang akan kita pelajari bersama:

- **4.2 Elemen Gambar img**: Dasar tag `<img>` dan memahami bahwa HTML tidak menyimpan gambar langsung di dalamnya.
- **4.3 Atribut src & alt**: Menentukan alamat gambar dan teks alternatif yang ramah pembaca layar (aksesibilitas).
- **4.4 Dimensi Gambar**: Memahami pentingnya atribut `width` and `height` untuk mencegah *Cumulative Layout Shift (CLS)*.
- **4.5 figure & figcaption**: Mengelompokkan gambar dan keterangan secara semantik.
- **4.6 Gambar Responsif**: Konsep dasar tag `<picture>`, `<source>`, `srcset`, dan `sizes`.
- **4.7 Elemen audio & video**: Menampilkan pemutar suara dan video langsung di browser.
- **4.8 Atribut Kontrol & Autoplay**: Mengatur pemutaran media secara otomatis, bisu, atau berulang.
- **4.9 Elemen iframe**: Menyisipkan konten interaktif dari website luar (seperti YouTube atau Google Maps).
- **4.10 Organisasi File Media**: Menyusun folder aset media agar rapi dan teratur.
- **4.11 Studi Kasus**: Memasang foto profil dan peta lokasi di dalam kelanjutan portfolio multi-halaman.
- **4.12 Mini Project**: Memperkaya halaman portfolio pribadimu dengan galeri foto dan media.
- **4.13 Challenge**: Tantangan mendiri membuat layout kartu proyek bergambar.
- **4.14 Error Corner**: Mengulas kesalahan umum penulisan atribut media.
- **4.15 Ringkasan**: Rangkuman seluruh elemen media beserta kegunaannya.
