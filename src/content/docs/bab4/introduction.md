title: "4.0 Introduction — CSS Box Model & Sizing"
description: "Memahami konsep fundamental Box Model — Content, Padding, Border, Margin, serta mengapa box-sizing: border-box menjadi standar industri."
---

Di mata browser, setiap elemen HTML di halaman web adalah sebuah kotak persegi (Box).

Box Model terdiri dari 4 lapisan konsentris:
1. Content Box: Area tempat teks atau gambar berada.
2. Padding Box: Ruang napas internal di antara konten dan border.
3. Border Box: Garis tepi yang membungkus padding dan konten.
4. Margin Box: Ruang kosong eksternal yang memisahkan kotak dari elemen tetangganya.

Di BAB 4 ini, kamu akan memahami cara kerja `box-sizing: border-box` yang mencegah 90% bug ukuran layout di web.
