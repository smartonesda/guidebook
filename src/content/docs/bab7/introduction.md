---
title: "7.0 Introduction — Modern CSS Grid (2D Layout)"
description: "Menguasai CSS Grid Layout 2 Dimensi — baris, kolom, fr units, repeat(), minmax(), auto-fit/auto-fill, dan grid-template-areas."
---

Jika Flexbox adalah raja layout 1 dimensi (baris ATAU kolom), maka CSS Grid adalah penguasa layout 2 dimensi (baris DAN kolom sekaligus).

Di BAB 7 ini, kamu akan mempelajari:
- Grid container & grid lines
- Unit pecahan fraksional: `fr`
- Fungsi ajaib responsif tanpa media queries: `repeat(auto-fit, minmax(280px, 1fr))`
- Tata letak visual deklaratif: `grid-template-areas`
- Subgrid untuk menyelaraskan anak elemen bertingkat
