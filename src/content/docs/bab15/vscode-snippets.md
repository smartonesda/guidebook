## ⌨️ 1. Pintasan Emmet Abbreviation (VS Code)

Ketikkan kode singkat Emmet di bawah ini di VS Code, lalu tekan tombol `Tab` atau `Enter`:

| Ketikkan Emmet | Kode HTML yang Dihasilkan |
|---|---|
| `!` | Membuat dokumen HTML5 dasar lengkap. |
| `link:css` | `<link rel="stylesheet" href="style.css">` |
| `script:src` | `<script src=""></script>` |
| `a:blank` | `<a href="" target="_blank" rel="noopener noreferrer"></a>` |
| `inp` | `<input type="text" name="" id="">` |
| `input:m` | `<input type="email" name="" id="">` |
| `input:b` | `<button type="submit"></button>` |
| `h1{Judul}` | `<h1>Judul</h1>` |
| `.card` | `<div class="card"></div>` |
| `#main` | `<div id="main"></div>` |
| `ul>li*3` | Membuat `<ul>` berisi 3 `<li>` sekaligus. |
| `header>nav>a*3` | Membuat elemen header, nav, dan 3 tag link di dalamnya. |

## 💻 2. Pintasan Keyboard VS Code Penting

- **`Shift + Alt + F`**: Merapikan indentasi seluruh kode HTML secara otomatis (*Format Document*).
- **`Alt + Up / Down`**: Memindahkan baris kode ke atas atau ke bawah.
- **`Shift + Alt + Up / Down`**: Duplikasi baris kode ke atas atau ke bawah.
- **`Ctrl + /`** (Windows) / **`Cmd + /`** (Mac): Menjadikan baris kode sebagai komentar `<!-- ... -->`.
- **`Ctrl + D`**: Memilih kata/tag berikutnya yang sama untuk diedit bersamaan (*Multi-cursor*).

---

## 🛠️ 3. Rekomendasi Ekstensi VS Code

1. **Prettier - Code Formatter**: Merapikan format spasi & indentasi secara otomatis saat file disimpan.
2. **HTMLHint**: Menampilkan garis bergerigi merah secara real-time pada kesalahan sintaks HTML.
3. **Auto Rename Tag**: Mengubah tag penutup secara otomatis ketika tag pembuka diedit.
4. **Auto Close Tag**: Menutup tag HTML secara otomatis begitu tag pembuka selesai diketik.
5. **Live Server**: Membuka server lokal di browser dengan fitur *Live Reload* instan.
