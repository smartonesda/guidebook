## 🧠 Rekap Konsep Utama BAB 11

### 1. Working Code vs Good Code vs Maintainable Code
- **Working**: Kode berjalan tapi berantakan.
- **Good**: Kode semantic, valid, dan accessible.
- **Maintainable**: Kode rapi, konsisten (2 spasi, lowercase), terorganisir, dan mudah dikembangkan oleh tim.

### 2. Standar Format Clean HTML
- **Indentasi**: 2 spasi secara konsisten.
- **Case**: Lowercase untuk tag dan atribut.
- **Quotes**: Double quotes (`"..."`) untuk nilai atribut.
- **Tag Penutup**: Selalu tutup tag pasangan.

### 3. Penamaan & Struktur File
- **File & Folder**: Gunakan `kebab-case.html` (huruf kecil, dipisah tanda hubung, tanpa spasi).
- **Aset**: Pisahkan gambar, CSS, dan JS ke dalam direktori `assets/`.

### 4. Validasi & Performa
- **W3C Validator**: Target 0 Error.
- **Performa Gambar**: Gunakan `loading="lazy"` untuk gambar di bawah layar, serta sertakan atribut `width` dan `height` untuk mencegah CLS.
- **Script**: Gunakan atribut `defer` pada `<script>` di `<head>`.
