Di bab ini, kamu akan mengubah cara pandangmu dari sekadar "bisa menulis CSS" menjadi "menulis CSS standar industri yang bersih, aman, dan mudah dipelihara".

Topik utama BAB 11:
- CSS Logical Properties: `margin-inline`, `padding-block`, `inset` untuk dukungan internasionalisasi (LTR & RTL)
- Native CSS Nesting: Menulis aturan bersarang langsung tanpa preprocessor
- Audit performa stylesheet & penghapusan dead CSS
- Checklist peninjauan kode (Code Review Guidelines)
