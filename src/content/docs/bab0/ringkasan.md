## 📝 Rekap Konsep Penting

Berikut adalah ringkasan konsep dasar yang wajib kamu ingat sebelum menulis kode HTML secara mendalam:

- **Internet vs Web**: Internet adalah infrastruktur kabel fisik (jalan raya), sedangkan Web adalah sistem informasi halaman web (gedung/toko) yang berada di atasnya.
- **Browser & Server**: Browser bertindak sebagai pemesan (*client*) yang membaca dan menggambar halaman, sedangkan Server bertindak sebagai penyedia file website.
- **Trio Web**: HTML bertindak sebagai **struktur/kerangka**, CSS sebagai **gaya/cat**, dan JavaScript sebagai **logika/interaksi**.
- **VS Code**: Editor kode yang kita gunakan untuk mengetik dan merapikan baris-baris kode secara otomatis.
- **Live Server**: Web server lokal kecil di komputer kita (`localhost` / `127.0.0.1`) agar browser bisa auto-refresh.
- **DevTools**: Alat bawaan browser untuk memeriksa, menguji, dan mengintip kode HTML halaman web.

## 🚦 Checklist Kesiapan Sebelum Masuk BAB 1

Pastikan kamu mencentang semua poin kesiapan di bawah ini sebelum melanjutkan ke bab berikutnya:

- [ ] Memahami perbedaan peran HTML, CSS, dan JavaScript secara konseptual.
- [ ] Memahami bagaimana browser meminta dan menerjemahkan file HTML dari server.
- [ ] Sudah memasang **Visual Studio Code** dan **Google Chrome** di komputermu.
- [ ] Sudah memasang ekstensi **Live Server** di VS Code.
- [ ] Sudah mengaktifkan fitur **Auto Save** agar kodemu tersimpan otomatis.
- [ ] Berhasil membuat file **`index.html`** pertama di dalam folder proyek khusus.
- [ ] Berhasil membuka file `index.html` tersebut di browser melalui alamat Live Server (`127.0.0.1:5500`).
- [ ] Pernah mencoba mengintip atau mengedit teks secara sementara menggunakan **Chrome DevTools**.

Jika semua poin di atas sudah terpenuhi, kamu sudah memiliki fondasi dan mental model yang sangat kuat untuk mulai membedah kode HTML.
