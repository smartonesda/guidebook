Selamat datang di **HTML Guidebook**!

Sebelum kita mengetik satu baris kode pun, mari kita luruskan satu hal: guidebook ini **tidak dirancang untuk membuatmu sekadar menghafal puluhan tag HTML**. Di dunia kerja nyata, menghafal kode tidaklah penting karena semua dokumentasi bisa dicari di internet.

Yang paling penting adalah **memahami konsep dasarnya**. Ketika kamu memahami *mengapa* sebuah tag digunakan dan *bagaimana* browser membacanya, kamu akan bisa memecahkan error apa pun dengan mudah.

---

## 🎯 Target Kita: Memahami, Mencoba, Membangun

Perjalanan belajarmu di guidebook ini akan menggunakan pendekatan yang sangat praktis:

1. **Memahami (Why & What)**: Kita mulai dari kegunaan nyata sebuah teknologi dalam kehidupan sehari-hari sebelum membedah definisinya.
2. **Mencoba (Practice)**: Setiap penjelasan teori akan langsung diikuti contoh kode pendek yang bisa kamu ketik ulang dan modifikasi secara mandiri.
3. **Membangun (Build)**: Di akhir bab, kamu akan ditantang membuat proyek web sederhana yang valid dan bisa langsung kamu masukkan ke portofolio hasil karyamu.

---

## 🗺️ Peta Pembelajaran BAB 0

Di bab pembuka ini, kita akan fokus menyelaraskan pemahaman awal (mental model) tentang dunia web sebelum masuk ke hal teknis:

- **0.2 Selamat Datang**: Kenapa belajar coding tidak seseram yang kamu bayangkan.
- **0.3 Cara Menggunakan Guidebook**: Tips belajar efektif dan membangun kebiasaan mandiri.
- **0.4 Mengenal Dunia Web**: Bagaimana browser dan server saling berkomunikasi.
- **0.5 HTML, CSS, JavaScript**: Mengenal trio teknologi pembangun setiap halaman web.
- **0.6 Persiapan Software**: Memasang peralatan perang yang ringan dan gratis.
- **0.7 Setup VS Code**: Konfigurasi dasar untuk editor kodemu agar nyaman digunakan.
- **0.8 File Pertama**: Menulis baris kode pertama dan menyimpannya secara benar.
- **0.9 Membuka di Browser**: Cara melihat langsung hasil karyamu di layar monitor.
- **0.10 Mengenal DevTools**: Cara mengintip "isi perut" halaman web buatanmu.
- **0.11 Error Corner**: Belajar mendeteksi dan menyelesaikan error umum pemula.
- **0.12 Ringkasan**: Rekap singkat seluruh poin penting di bab ini.
