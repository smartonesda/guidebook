Selamat datang di **CSS Guidebook**!

Sebelum kita mulai menulis baris CSS pertama, mari kita luruskan satu hal mendasar: guidebook ini **tidak dirancang untuk membuatmu menghafal ratusan nama properti CSS**. Di dunia kerja nyata, menghafal nama properti tidaklah penting karena semua dokumentasi resmi dan referensi sintaks dapat diakses dalam hitungan detik.

Yang paling penting adalah **memahami CSS sebagai sebuah sistem**. Ketika kamu memahami *mengapa* sebuah aturan bekerja, *bagaimana* browser menggabungkan HTML dengan CSS, dan *bagaimana* alur tata letak (layout) dihitung, kamu akan mampu men-debug dan menyelesaikan masalah tampilan web apa pun dengan percaya diri.

---

## Target Hasil Belajar (Learning Outcomes)

Setelah menyelesaikan BAB 0 ini, kamu akan mampu:

1. **Menjelaskan fungsi CSS** dengan bahasamu sendiri tanpa menghafal definisi kaku.
2. **Membedakan peran trio web**: HTML (struktur), CSS (presentasi/gaya), dan JavaScript (interaktivitas/logika).
3. **Memahami mental model browser**: bagaimana browser membaca HTML menjadi DOM, CSS menjadi CSSOM, lalu menggabungkannya menjadi Render Tree.
4. **Menghubungkan CSS ke HTML** menggunakan 3 metode (Inline, Internal, External) serta memahami kapan dan mengapa External CSS adalah standar industri.
5. **Menggunakan Browser DevTools** untuk menginspeksi elemen, mengubah nilai CSS secara langsung (live-edit), dan mencari tahu aturan mana yang aktif.
6. **Membaca dokumentasi resmi (MDN)** dan memahami notasi sintaks CSS modern.
7. **Menghindari 5 kesalahan pemula** yang paling sering membuat CSS tidak bekerja.
8. **Membangun halaman web ber-style pertamamu** melalui mini project mandiri.

## Peta Pembelajaran BAB 0

Bab ini disusun secara bertahap agar kamu tidak merasa kewalahan:

- **0.1 Introduction**: Peta konsep dan target capaian bab pembuka.
- **0.2 Selamat Datang**: Mengatasi rasa takut belajar coding dan membangun pola pikir eksperimen.
- **0.3 Cara Menggunakan Guidebook**: Strategi belajar efektif (Pahami &rarr; Coba &rarr; Rusak &rarr; Perbaiki).
- **0.4 Apa itu CSS?**: Mengapa web membutuhkan bahasa tersendiri untuk styling dan tata letak.
- **0.5 Cara Browser Membaca CSS**: Alur kerja DOM, CSSOM, Render Tree, Layout, dan Painting.
- **0.6 HTML vs CSS vs JavaScript**: Pembagian peran yang jelas dalam ekosistem frontend web.
- **0.7 Apa yang Sebenarnya Dilakukan CSS?**: Mengontrol warna, tipografi, model kotak, dan sistem layout.
- **0.8 Tools yang Digunakan**: Memilih editor, browser, dan ekstensi yang tepat.
- **0.9 Setup VS Code**: Konfigurasi editor agar efisien saat menulis CSS.
- **0.10 Tiga Cara Memasang CSS**: Membedah Inline, Internal, dan External Stylesheet beserta kelebihan dan kekurangannya.
- **0.11 Cara Membaca Dokumentasi CSS**: Menavigasi MDN Web Docs dan memahami nilai sintaks.
- **0.12 Mengenal Browser DevTools**: Menginspeksi elemen dan mengubah style secara langsung di layar.
- **0.13 Error Corner**: Diagnosis 5 error klasik pemula dan cara memperbaikinya.
- **0.14 Ringkasan & Mini Project**: Merangkum fondasi mental dan membangun proyek "My First Styled Page".
