title: "8.0 Introduction — Responsive & Fluid Design"
description: "Filosofi Mobile-First, Range Media Queries modern, Fluid Typography dengan clamp(), dan Container Queries (@container)."
---

Website modern tidak lagi dibuat untuk satu ukuran layar statis. Sebuah website harus tampil sempurna di layar jam tangan, ponsel 360px, tablet, laptop, hingga monitor 4K.

Di BAB 8 ini, kamu akan mempelajari:
- Paradigma Mobile-First sejati
- Modern Media Queries: sintaks range `(width >= 768px)`
- Fluid Typography & Fluid Spacing dengan fungsi `clamp(min, preferred, max)`
- Container Queries (`@container`): menyesuaikan komponen berdasarkan lebar induknya, bukan lebar viewport layar!
