# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

- Astro v7.x (Static Site Generator)
- Astro Starlight (documentation theme)
- MDX (rich Markdown components)
- Expressive Code (syntax-highlighted code blocks)
- Sharp (image optimization)
- Deploy: Vercel (primary) · GitHub Pages (mirror, base /html-guidebook/)

## Users

Primary: siswa SMK Rekayasa Perangkat Lunak (RPL), usia 15–18, belajar dalam konteks kelas dengan guru.
Secondary: mahasiswa Informatika/Ilmu Komputer dan self-taught developer pemula (Indonesia).
Tertiary: guru/mentor programming yang menggunakan guidebook sebagai bahan ajar.

Operating context: dibaca di laptop sekolah, HP, atau tablet; koneksi internet bervariasi; sebagian besar awam terminal.

## Purpose

Kurikulum HTML5 lengkap berbahasa Indonesia, berjenjang BAB 0–15, membawa pelajar dari nol hingga mampu membangun website nyata yang valid W3C, semantik, dan accessible. Setiap bab memiliki teori, studi kasus, mini project, challenge, dan error corner. Bab 12 = Mini Project Collection; Bab 13 = Final Project; Bab 14 = Challenge Collection; Bab 15 = HTML Handbook (referensi).

Diferensiasi: satu-satunya panduan HTML5 modern berbahasa Indonesia yang terstruktur seperti kurikulum sekolah dengan proyek linier terintegrasi (portofolio tumbuh tiap bab).

## Capabilities

- Dokumentasi interaktif full-text searchable (Pagefind)
- Dark mode & light mode otomatis
- Responsive: mobile, tablet, desktop
- Satu klik salin kode
- Syntax highlighting Expressive Code
- OG image untuk share sosial

## Constraints

- Seluruh konten WAJIB berbahasa Indonesia
- Lisensi MIT — bebas digunakan untuk pendidikan
- Materi harus tetap sesuai standar W3C HTML5
- Tidak boleh menggunakan konten yang menyesatkan atau tidak akurat secara teknis

## Voice

Santai tapi informatif; menggunakan analogi kehidupan nyata; menyapa pelajar dengan hangat; tidak menghakimi kesalahan (lihat "Error Corner" di setiap bab).
